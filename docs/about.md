  <span class="eyebrow">Overview</span>
  <h1>What is JapyScope?</h1>
  <p>JapyScope Remote is a custom, Raspberry Pi Zero W-based hand controller for GoTo telescope mounts — not limited to Dobsonian telescopes. It connects directly to the mount’s RJ12 hand-control port and currently uses INDI’s Sky-Watcher Alt-Az driver.</p>
  <h2>What you get</h2>
  <ul>
    <li>An e-paper controller interface with keypad and side wheel.</li>
    <li>A companion Web UI on your local network.</li>
    <li>Wi-Fi onboarding via a temporary JapyScope setup network.</li>
    <li>A browser-based mockup while the physical hardware is still being validated.</li>
  </ul>
  <p class="notice">The project is under active development. The installer and software are real; the final e-paper panel and mount validation remain open hardware work.</p>

Saving the secondary network only stores it, it won't connect on its own, since it's often set up somewhere its network isn't even in range yet. Switching to it (or back to Primary) is done by Dev Tools code 5001. EXPERIMENTAL, DO NOT USE WITHOUT READING MANUAL FIRST!

Mount WiFi (SynScan)

The mount's own SynScan WiFi module, reached over the network instead of RJ12/Bluetooth. Use 192.168.4.1 if the mount is in its own Access Point mode, or its LAN IP (check your router) if it's in Station mode on your WiFi. Connecting is done on the controller's Dev Tools (code 9600).

Service Control

Software Update

Checks GitHub for a newer JapyScope release and, if found, downloads, verifies, and installs it. The controller and Web UI restart automatically when it finishes; a failed update rolls back on its own. Progress and results appear in Diagnostics → japyscope-update.

Joystick (optional)

An external KY-023-style analog joystick can be wired up on its own cable (see docs/WIRING.md) as an alternative to the rotary encoder for menu navigation, plus manual N/S/E/W jogging during alignment and while tracking. Leave this unchecked if you don't have one connected — the controller works exactly the same without it.

Hardware Bring-up (Development)

Check a component to run it simulated instead of real hardware. Restart the controller (System page) after changing these.

Simulating keypad, encoder, or joystick reads keypresses from a terminal, which needs an interactive session — it will never receive input when the controller runs as the japyscope-app.service systemd unit (no terminal attached). To actually use them, stop the service and run python3 -m firmware.main --simulate directly over SSH instead. display has no such requirement and works normally under the service. joystick's checkbox here only matters once "Joystick connected" above is checked.
